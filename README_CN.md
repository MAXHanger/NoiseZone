# Noise Zone —— Godot 4 噪声遮罩 CRT 特效 Shader

一个 `canvas_item` shader，把 CRT 风格特效约束在一张黑白遮罩内：
**湍流马赛克 + 内外发光 + 电视雪花噪点 + 画面扭曲折射 + 湍流溶解**。

- 此效果受启发于游戏`phigros`里的`Noisefield`，本shader旨在尽量还原它。

### 仍需优化或者添加的效果

1. 判定区内部会有无数的`微小矩形粒子`特效，形成混乱、浑浊和故障的效果，我用过随机函数生成和3D噪声图Z轴演化模拟粒子，但是效果仍然不太对。
2. `缩放比例`似乎不太对，矩形的扭曲程度感觉过于小了，如果调大`displacement_scale`又会变得混乱，不知道是窗口尺寸大小问题还是参数设置问题。
3. 扭曲的方式似乎不对，可能和代码的扭曲方式有关，也可能和`Noise Tex`的纹理有关。

- 代码仍需完善和优化，欢迎各位大佬来指正批评。

## 特性

- 由噪声贴图驱动的"马赛克块量化"湍流
- 遮罩边缘的柔和**内发光 / 外发光**
- 可选描边样式：内外各 1 像素（默认）、仅内边缘、仅外边缘（`edge_mode`）
- 电视雪花噪点，强度和刷新频率可调
- 对节点下方游戏画面的屏幕空间扭曲折射
- 湍流溶解，蚕食特效层形成剥落感

## 环境要求

- Godot **4.x**（建议 4.2+）
- 一张二维噪声贴图用于湍流（推荐 `NoiseTexture2D` + `FastNoiseLite`）

## 快速上手

### 1. 绘制遮罩

1. 在场景中添加一个 **`SubViewport`** 节点（例如命名为 `MaskView`）。
2. 勾选 `transparent_bg = true`，并把它的 `size` 设置成与最终渲染区域**相同的分辨率**（否则遮罩会被拉伸）。
3. 把 **Render Target → Update Mode** 设为 **Always**（即 `render_target_update_mode = 4`）。不设的话遮罩可能停留在第一帧不再刷新。
4. 在 `MaskView` 下添加 **`ColorRect`** 子节点来绘制遮罩：
   - **白色** —— 特效显示的区域；
   - **黑色** —— 挖洞，特效在此被丢弃；
   - 未被矩形覆盖的区域是透明的，按黑色处理（同样被丢弃）。

### 2. 把遮罩传给 shader

1. 添加一个铺满屏幕的 **`TextureRect`**。
2. 在其 **Texture** 槽位中新建一个 **`ViewportTexture`**，并把 **Viewport Path** 指向 `MaskView` 节点（可以直接把 SubViewport 节点拖进该属性）。
3. 在 **CanvasItem → Material** 中新建 **`ShaderMaterial`**，加载 `noise_zone.gdshader`。
4. 给 **`noise_tex`** 参数指定一张噪声贴图（`NoiseTexture2D` + `FastNoiseLite` 即可）。不指定的话湍流不会动。

### 3. 把游戏画面放在下面

`screen_tex` 使用了 `hint_screen_texture`，shader 会自动抓取同一画布/视口中渲染在 `TextureRect` **下方**的所有内容。把游戏内容节点放在它下面即可。

项目内附带可直接运行的示例场景 [`noise_show.tscn`](noise_show.tscn)。

## 遮罩的工作原理

- shader 只读取遮罩的**红色通道**并以 `0.5` 硬阈值二值化：白色 → 内部，黑色/透明 → 外部。
- 外部像素会被**丢弃**（1 像素描边和外光晕除外），因此特效永远不会溢出遮罩。
- 遮罩内部按 `block_size` 像素的马赛克块量化采样，并叠加湍流置换——这就是边缘"沸腾"效果的来源。

## 参数说明

| 名称 | 默认值 | 范围 | 说明 |
|---|---|---|---|
| `block_color` | (0.5, 0.05, 0.05, 0.8) | 颜色 | 遮罩内部的基础底色 |
| `glow_color` | (1, 0.2, 0.2, 1) | 颜色 | 发光/描边颜色 |
| `glow_intensity` | 2.0 | 1.0 – 5.0 | 发光亮度倍率 |
| `glow_width` | 8.0 | 0 – 32 | 光晕宽度（像素），`0` 关闭光晕 |
| `glow_falloff` | 2.0 | 0.5 – 8.0 | 光晕衰减指数（越大收得越紧） |
| `glow_opacity` | 0.5 | 0 – 1 | 光晕整体不透明度 |
| `edge_mode` | 0 | 0 – 2 | 描边样式：`0` = 内外各 1 像素（默认），`1` = 仅内边缘，`2` = 仅外边缘 |
| `noise_tex` | — | 纹理 | 湍流噪声贴图（推荐 `NoiseTexture2D`） |
| `evolution_speed` | 1.0 | — | 湍流演化速度 |
| `turbulence_scale` | (2, 2) | vec2 | 噪声采样缩放 |
| `displacement_scale` | 0.04 | 0 – 1.2 | 边缘置换幅度 |
| `block_size` | 8.0 | 1 – 64 | 马赛克块大小（像素） |
| `noise_grain_strength` | 0.35 | 0 – 3 | 雪花噪点强度（0 = 无，1 = 纯雪花） |
| `noise_grain_speed` | 45.0 | 1 – 100 | 噪点刷新频率（Hz，30 – 60 接近老电视刷新率） |
| `noise_mode` | 0 | 0 – 1 | 噪点采样方式：`0` = 原始 UV（细密），`1` = 块量化（像素块状） |
| `screen_distortion_strength` | 0.035 | 0 – 5 | 对游戏画面的折射扭曲强度 |
| `overlay_opacity` | 0.65 | 0 – 1 | 顶层折射画面不透明度（`0` = 纯原画，`1` = 纯折射） |
| `dissolve_threshold` | 0.45 | 0 – 1 | 溶解阈值（控制被掏空的面积） |
| `dissolve_contrast` | 0.15 | 0.01 – 5.5 | 溶解对比度（越小边缘越柔和） |
| `blend_mode` | 0 | 0 – 1 | 合成方式：`0` = 常规透明度混合，`1` = 加法发光叠加 |
| `light_radius` | 400 | 0 – 2000 | `light()`：2D 光源有效半径（像素） |
| `light_falloff` | 2.0 | 0.5 – 5 | `light()`：衰减指数 |
| `light_ambient` | 0.05 | 0 – 1 | `light()`：环境底光 |

## 注意事项与技巧

- **性能**：光晕的 8 方向逐像素探测是开销热点。大面积遮罩下建议 `glow_width` 不超过 16；设为 `0` 可完全跳过光晕。
- **旋转遮罩**：由于采样按块量化，旋转遮罩矩形可能导致某些方向的边缘扰动减弱——这是马赛克方案的已知特性。
- `light_*` 参数只作用于 `light()` 函数（即 2D 光源照射本节点时的表现）。
- `block_size` 较大（32+）时光晕会显得块状，因为描边跟随块网格走。
